> projects

Selected work

National Health Network Design (BGP & Dual-ISP + ACL)

Networking

Designed and implemented a national hospital network connecting JDWNRH, Mongar, and Gelephu through two independent ISPs. Used BGP across five autonomous systems for full route exchange, configured local-preference and prefix-list policies so the hospital network favored one ISP while avoiding transit, and applied an extended ACL to restrict the patient-records server to a single authorized hospital.

  • Cisco IOS
  • BGP
  • Multi-AS Routing
  • ACL
  • Packet Tracer

Smart Hall Booking System

Software

Developed a college-based hall booking management system that simplifies reservation requests, provides real-time hall availability, manages booking approvals, and prevents scheduling conflicts. The system includes role-based access for students, faculty members, and administrators, along with notifications and hall usage reports.

  • Frontend Development
